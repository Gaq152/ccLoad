域名与 IP 访问

支持域名、IP 和可选端口，例如 api.example.com、10.0.0.8:8080。不填写端口时匹配该地址的所有端口；HTTP/HTTPS 由入口决定，不在此处限制。添加规则后，未列出的地址将被拒绝。

管理密码

密码以 bcrypt 哈希存储于数据库，任何地方不保存明文。修改后所有登录会话将失效，需要重新登录。忘记密码时可用环境变量 CCLOAD_PASS_RESET 重置（详见日志提示）。

使用 Google Authenticator 等验证器 App 扫码绑定后，登录除密码外还需输入动态验证码。即使密码泄露，攻击者也无法登录。

登录页人机验证（Cloudflare Turnstile）

开启后登录页嵌入 Turnstile 验证组件，拦截机器人脚本爆破密码。公网部署建议开启；需同时配置 Site Key 和 Secret Key 才生效。
